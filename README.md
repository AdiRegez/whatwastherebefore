# What Was There Before / Was vorher da war

Ein interaktives Kunstwerk, das den Schreibprozess als Palimpsest sichtbar macht: Tempo, Pausen,
Streichungen, Ergänzungen und die Spur der Maus.
*An interactive artwork that makes the writing process visible as a palimpsest.*

**Werk / Work:** https://whatwastherebefore.com  
**Repositorium / Repository:** https://github.com/AdiRegez/whatwastherebefore  
**Idee, Konzept, Gestaltung und Programmierung:** Adrian Regez · contact@whatwastherebefore.com

## Aufbau / Structure

| Datei | Inhalt |
| --- | --- |
| `index.html` | das Werk |
| `about.html` | Idee, verwandte Arbeiten, Literatur |
| `research.html` | für Forschende, Zitieren, Quellcode, Lizenz, Versionen |
| `privacy.html`, `legal.html` | Datenschutz, Impressum und Kontakt |
| `info.html` | Weiterleitung für alte Links |
| `site.js` | Werkangaben (Name, Version, DOI, Repositorium), Sprachumschaltung, Metadaten – **nur hier pflegen** |
| `script.js` | Aufzeichnung und Darstellung des Schreibprozesses |
| `style.css` | Gestaltung |
| `robots.txt`, `sitemap.xml` | Suchmaschinen |

Das Werk läuft vollständig im Browser, ohne Build-Schritt, ohne Abhängigkeiten, ohne Datenübertragung.
Zum lokalen Ausprobieren genügt es, `index.html` im Browser zu öffnen.
